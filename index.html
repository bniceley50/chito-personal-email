Chito Personal Email

Chito is a private personal assistant. Its email connection lets its owner compose and send text emails from their existing Gmail account when they explicitly ask.

  • Send a requested message to one named recipient.
  • Save a local draft for review without sending it.
  • Check a saved outbox record and the message identifier returned by Gmail.

The connection requests permission to send Gmail messages and verify the connected email identity. It does not request permission to read the Gmail inbox. Only the authenticated owner can invoke sending from the connected account.

This is a personal-use integration, not a public email service. This informational website has no sign-in, account registration, or mailbox access.
